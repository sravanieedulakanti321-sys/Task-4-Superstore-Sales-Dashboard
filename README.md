# Task 4 – Superstore Sales & Profitability Dashboard

## Project Overview
An interactive dashboard project using the Sample Superstore dataset to analyze sales, profit, products, categories, and regional performance.

## Objective
To transform raw sales data into meaningful visual insights and support data-driven business decisions.

## Tools Used
- Power BI
- Tableau
- Excel / CSV
- Data Visualization

## Key KPIs
- Total Sales
- Total Profit
- Profit Margin
- Total Orders
- Total Quantity

## Dashboard Visualizations
- Sales & Profit Trend
- Sales by Category
- Profit by Region
- Sub-Category Performance
- Top & Bottom Products
- Interactive Filters
